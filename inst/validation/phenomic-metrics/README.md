# Phenomic metrics: implementation and validation

The new API is `get_enrichment_mask()`, `classify_branch_rates()`,
`phenomic_diversity()`, `phenomic_coordination()` and `phenomic_metrics()`.
`branch_rate_pipeline(..., phenomic = list(...))` runs them automatically.
The rendered pipeline vignette provides formulas, the diagram and all examples.

## Provenance and deliberate corrections

The formulas come from Sergei Tarasov's `Hymenoptera_paper/R/utils-ST.R`:
`get_enrichment_mask()`, `diversity_metric(type="Neff_scaled")`, and
`relative_null_metric(type="scaled")`. The latter was enrichment strength Se,
now phenomic coordination Pc. `make-Pc.Rmd` confirms its denominator is all
active lineages; `make-Neff-plus.Rmd` and `make-Neff-minus.Rmd` confirm that
thresholds and metrics are calculated within each map before averaging.
The source checkout was at c22dfaa65726162f2e3e6100149a4f5acc3de46e.
`legacy-reference.R` preserves the three function bodies for a separate
compatibility comparison and records their source-file MD5. They are not
loaded into the package namespace. No source-repository files were changed.

Corrections are explicit: constant columns are unclassified by default; the
both-directions mask is the union of the two masks; time ages are calculated
from tree height (not reversed labels); and descendants replace ancestors at
exact nodes. `constant="include"` reproduces the old directional treatment of
constant columns. `ties="include"` is the default used in the original scripts;
`ties="exclude"` implements strict above/below wording. Actual selected counts
and cases of overlapping classifications are retained in the results.

## Validation protocol

- Exact binary-pattern examples check Neff, Pc, zero patterns, conditional
  versus unconditional denominators, skewed pattern frequencies and invariance
  to permutations. Their expected answers are analytical, not generated by the
  implementation being tested.
- Replicate-specific fixtures check thresholds, map pairing, nonlinear
  before-summary calculations, irregular time grids, exact node boundaries,
  constant-region handling, overlap warnings and invalid inputs.
- Actual fitting/mapping tests compare original maps, in-memory counts and
  disk-backed counts through the higher-order wrapper.
- One hundred fixed-seed compatibility cases check old/new directional masks,
  Neff and scaled Se/Pc (results/legacy-compatibility.txt).
- Four prespecified simulation pilots use the existing 100-tip, root-150-Ma
  tree. Each dataset has 20 binary characters in two disjoint 10-character
  regions and equal root-state frequencies. The baseline is 0.002/Myr;
  acceleration is tenfold and deceleration one tenth. Shifted branches are
  whole young branches in the existing focal 45-tip clade (76 branches);
  mosaic acceleration affects the other young branches for region B.
- Homogeneous ER is fitted separately with fit_models (corHMM, one random
  restart); paramo_stm (phytools) supplies 25 maps per character. No filtering,
  pruning or selection based on recovery is performed. Four datasets yield
  80 fits and 2,000 conditional maps. This is a smoke test, not a power study.

## Interpretation

Accelerated classification precision is 0.921 for coordinated and 0.900 for
mosaic shifts. Classification-frequency AUC is 0.695/0.677: the top-5% rule
selects only a subset of a large shifted clade. Homogeneous rates still give
about 5% accelerated calls. The slow-regime pilot labels 83.7% of entries slow
with inclusive ties, whereas strict lower thresholds label none; many event
counts are zero. These are descriptive tails, not calibrated significance tests.

Neff/Pc from realized histories can already differ greatly from metrics applied
to the generating rate vectors. For example, present Pc in the coordinated
scenario is 0.45 from generating rates, 0.070 from true histories, and 0.0702
from reconstructed histories. This pilot verifies the pipeline and illustrates
its limitations; it does not establish recovery of latent regime magnitudes or
an independence-based measure of coordination. Mapping quantiles are conditional
on fitted Q, tree and observations.

Run from a writable copy with the development package installed:

```sh
Rscript run-pilot.R new-results
```

The saved run under `results/` is preserved. `summarize-pilot.R` summarizes the
bundled results, compares the legacy formulas, computes tie sensitivity and
regenerates the PDF/PNG using the shared branch-rate validation figure style.
