This workflow estimates mapped change rates for a combined character or an anatomical group. Each character is first fitted and mapped separately. For each map replicate, its changes are counted on each branch; counts are summed across the selected characters and divided by branch duration. Marginal rates average these branch rates across the sampled lineages present at each age.

The branch-specific estimator retains Sergei Tarasov’s Hymenoptera functions. branch_rate_pipeline() adds group handling, normalization, predefined branch comparisons and a consistent final result. It does not require discretizing histories or constructing a stacked-state map.

Pipeline and function names

The full pipeline. Branch and marginal summaries retain map replicates until the final statistical summary. Anatomical groups are processed separately.

The diagram names the public entry points. Internally, the higher-order wrapper summarizes already computed rate samples, so it does not repeat amalgamation. branch_rate_thru_time_Multi() calls branch_rate_thru_time() separately for each replicate before calculating uncertainty.

Function Role
fit_models() Fit and compare candidate Q models per character.

Fit models and sample histories

The following small example is executable. The rows identify taxa, and each column is a separate binary character. In this example all characters are variable; inspect the fitting and mapping status tables before analyzing a new dataset. Failed or skipped characters must not disappear silently.

tree <- ape::read.tree(text =
  "(((a:1,b:1):1,(c:1,d:1):1):1,((e:1,f:1):1,(g:1,h:1):1):1);")
characters <- cbind(
  char1 = c("0", "0", "0", "0", "1", "1", "1", "1"),
  char2 = c("0", "0", "1", "1", "0", "0", "1", "1"),
  char3 = c("1", "1", "0", "0", "0", "0", "1", "1"))
rownames(characters) <- tree$tip.label

fits <- fit_models(tree, characters, models = c("ER", "SYM", "ARD"),
                    root_p = "equal", criterion = "AICc", nstarts = 0,

The same root setting is carried from fitting to mapping. Binary ER and SYM represent the same model and are not fitted twice. Model selection and fixed-Q mapping do not propagate uncertainty in Q or model choice into the subsequent mapping intervals. See the fitting help pages for custom Q index matrices, missing and ambiguous observations, and checkpoint/resumption settings.

If maps were generated elsewhere, supply the same structure directly: list(char1 = maps_for_char1, char2 = maps_for_char2). For example, phytools::make.simmap() supplies each character’s map list. These must be the original maps, before discretization or stacked-state amalgamation.

The mapping result can also be passed directly. This reads one character’s branch-count samples at a time and supports disk-backed or count-only runs:

direct <- branch_rate_pipeline(mapped, groups, normalize = "characters",
                                time_points = seq(3, 0, by = -0.1),
                                time_scale = "age")
stopifnot(isTRUE(all.equal(direct$branch_summary, result$branch_summary)))

Count-only storage is sufficient for branch-specific and marginal rates, but cannot reproduce the transition times required by stacked-map analyses.

region_A and region_B overlap in char2. They are separate results; they are never summed to produce the combined group. The combined group explicitly contains the three unique characters. A named list returned by RAC_query() can be used as groups when all of its character IDs occur in maps.

With normalize = "none", rates are total character changes per time unit. With normalize = "characters", samples, means, SDs and interval bounds are all divided by the number of characters in their group. This makes units comparable across differently sized groups; it does not correct differences in state spaces or data quality.

Every lower-level function

For branch b, character c and map replicate m, let N be the reconstructed number of changes and L the branch duration. The combined rate is

\[ r_{bm} = \frac{\sum_c N_{bcm}}{L_b}. \]

This estimates a realized mapped change rate, rather than fitting a separate Q matrix to each branch. Reversals are counted. Adjacent segments labelled with the same state do not create a change.

The default time_scale = "root" preserves the original interface: supplied times are elapsed from the root. time_scale = "age" accepts ages before the present. Returned time always means age before the present. At an internal node, descendant branches contribute instead of their ancestor; at the present, terminal branches contribute their limiting rates. Marginal reconstruction requires a rooted ultrametric tree. Branch-only reconstruction is available with marginal = FALSE.

Predefined clade contrasts

Define focal and reference branches before examining inferred rates. The example below compares the terminal branches of two named tip groups. It illustrates the interface, rather than a biological hypothesis about this toy dataset. A real clade comparison can include internal branches as well.

focal_tips <- match(c("a", "b", "c", "d"), tree$tip.label)
reference_tips <- match(c("e", "f", "g", "h"), tree$tip.label)
focal <- which(tree$edge[, 2] %in% focal_tips)
reference <- which(tree$edge[, 2] %in% reference_tips)
comparison <- branch_rate_contrast(combined, focal, reference)
comparison$summary

By default, rates within each branch set are weighted by branch duration. The resulting value is total mapped changes divided by total lineage time. weighting = "equal" instead treats branches equally. Differences and ratios are calculated within each replicate and then summarized. If a reference rate is zero, its ratio is undefined and this is reported explicitly; differences remain available. There is no automatic pseudocount.

fraction_focal_greater is not a p-value. The intervals condition on the mapping model. They are not automatically calibrated confidence intervals for generating rate ratios, and selecting high-rate branches from the same result would make a subsequent contrast circular.

Rate-heterogeneity validation

The reproducible benchmark is installed with the package in validation/branch-rates. It uses the previously specified 100-tip tree with a root age of 150 Ma. The focal 45-tip clade contains 76 whole branches whose parent age is at most 50 Ma; 70 other young branches serve as the reference. Branches crossing 50 Ma retain the baseline rate throughout.

There are 30 independently simulated datasets in each of two conditions, with 20 binary characters per dataset and equal root-state frequencies:

  • Homogeneous control: q = 0.002 per Myr on every branch.
  • Accelerated clade: q = 0.020 on focal young branches, and 0.002 elsewhere.

For this downstream benchmark, each character is reconstructed under its own homogeneous ER model fitted with phytools::fitMk(), followed by 50 conditional maps from phytools::make.simmap(). The same mapping assumptions are used for both conditions. This independent fitting route isolates the downstream estimator; the executable example above separately tests the package’s fit_models() and paramo_stm() interface.

The simulator uses the exact symmetric-binary construction: Poisson event counts, uniformly distributed event times conditional on the count, and state flips inherited along the tree. Its event means and endpoint-state frequencies are checked against the analytic Mk distribution. True histories are retained to distinguish simulation/accounting correctness from inference using only tip observations. All characters, including invariant tip patterns, are retained in the benchmark. No histories are selected for favourable recovery. Unidentified high-rate fitting plateaus stop a run with saved diagnostics rather than triggering silent character removal.

Condition Datasets Median AUC Median ratio Interval excludes equal rates Interval covers true ratio
Homogeneous 30 0.498 1.03 9/30 21/30
10-fold acceleration 30 0.914 4.10 30/30 0/30

Validation on the fixed 100-tip tree. Each point represents one independently simulated character dataset. AUC describes discrimination between focal and reference young branches; it is not a branch-wise significance test.

The validation report separates branch-ranking discrimination, recovered fold change, coverage of the generating ratio, and the frequency with which the conditional mapping interval excludes equal rates under the homogeneous control. These are distinct properties. Good localization can coexist with substantial attenuation of the generating fold increase.

In the homogeneous control, the conditional interval excluded equal rates in 9/30 datasets. Under a true ten-fold acceleration, the median inferred ratio was 4.1 and the median AUC was 0.914; the interval covered the generating ratio in 0/30 datasets. Thus the method localized the strong accelerated regime in this design, but its conditional mapping intervals are unsuitable as nominal 5% tests of underlying rate heterogeneity or as calibrated intervals for the generating fold change.

The fixed-tree benchmark does not establish robustness to incomplete taxon sampling, phylogenetic error or polytomies. Nor does it measure adaptation or provide a calibrated discovery test for unknown accelerated branches. The number of simulated datasets is too small to establish precise tail error rates; raw results and their counts are supplied for interpretation.

To rerun the benchmark, copy its installed directory into a writable folder and run Rscript --vanilla run-validation.R. Optional arguments specify the output directory, datasets per condition and maps per character. Environment variables ONTO_FIRST_DATASET and ONTO_LAST_DATASET allow disjoint chunks; seeds are independent of worker scheduling and completed datasets are reused.

Input and uncertainty checks

  • All characters must share the tree, tip labels, edge order, branch lengths and map sample size. Edge order is checked, not silently inferred.
  • Branch lengths and mapped segment durations must be positive. Segment durations must sum to their corresponding branch length.
  • Map replicate identities are retained through amalgamation, normalization, comparisons and marginalization. Independently sampled character histories can be paired by position; dependent characters require joint draws.
  • Fixed-Q mapping intervals exclude uncertainty in fitted Q, model choice, topology, dating and taxon sampling. A larger number of maps reduces Monte Carlo error but does not remove those limitations.
